# cedar-cabi

vestitus-llm-proxy's self-built shim over a **commit-pinned** `cedar-policy`
(per ADR-001: never the upstream `com.cedarpolicy:cedar-java` jar; source-pin by
commit; build + attest ourselves; embed via the Java FFM API + this shim).

## Status: Plan 03b — `extern "C"` runtime shim (this sub-plan)

The crate now exposes a minimal, fail-closed, panic-safe C ABI over the pinned
Cedar **runtime** entrypoints (ADR-001: runtime only — no analysis/CLI surface;
that is the Cedar CLI, sub-plan 03e):

- `CedarResult` — `Deny=0, Allow=1, Valid=2, Invalid=3, Error=-1` (`int32_t`).
- `cedar_is_authorized(policies, principal, action, resource, context_json,
  entities_json, out_diag) -> CedarResult` — authorize one request. Returns
  `Allow` ONLY on a clean Cedar `Decision::Allow`; `Deny` on a clean deny (with
  reasons in `out_diag`); `Error` on any null/parse/eval failure or panic.
- `cedar_validate(schema_src, policies_src, out_diag) -> CedarResult` —
  registration-time type/schema validation under Strict mode. `Valid` only on a
  clean pass (no validation errors); validation *warnings* do not block here —
  the deep self-permissive / analyzability rejection (spec §9) is the Cedar-CLI
  gate (03e). `Invalid` on validation errors; `Error` on unparseable input/panic.
- `cedar_string_free(ptr)` — free any `out_diag` string this library returned.

Fail-closed by construction: no input or internal failure can yield `Allow`
or `Valid`; every `extern "C"` fn catches panics and never triggers UB
(spec §7 "Authorizer engine internal error => deny"). The non-allow/non-valid
diagnostics string lets the caller log + emit a reason-labeled metric
(spec §6 inv. 7). A `compile_error!` refuses `panic = "abort"` builds so the
`catch_unwind` boundary cannot be silently hollowed out.

- Generated C header (the 03d `jextract` input): `include/cedar_cabi.h`
  (regenerated by `build.rs`/cbindgen on every build; a test fails if it drifts).
- Pin & rule: `CEDAR_PIN`. Pinned API wrapped: `CEDAR_API_NOTES.md`.
- Build/test: `cargo test --locked`.
- Not a Maven module — built by cargo; wired into the JVM build via FFM in 03d.
